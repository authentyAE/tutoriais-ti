# Configurar Credenciais de Rede, para acesso FTP do Servidor

Para adicionar as credenciais de rede para acesso ao servidor (normalmente necessário para acessar algum caminho como `\\mdcserver`, no windows), siga os passos:

- Pesquise `Credenciais de Rede` no **Menu Iniciar**;
- Agra o **Gerenciador de Credenciais do Windows**;
- Clique em **Credenciais do Windows**;
- Clique em **Adicionar**;
- Adicione suas credenciais;

**Onde encontro as credenciais?** Elas estão em posse dos sócios da empresa.
